# Istruzioni Claude Code

Le regole complete del framework sono nel file `AGENTS.md`. Leggilo e applicalo. Le skill canoniche si trovano in `.agents/skills/`; quando il framework viene installato in un progetto Claude Code, l'installatore le copia in `.claude/skills/`. Prima di ogni nuovo step sostanziale leggi `PROJECT_SYNTHESIS.md`. Solo il Sintetizzatore può modificarlo.
